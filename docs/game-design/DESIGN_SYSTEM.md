# Design Philosophy

AlgoVerse is a pixel-art fantasy RPG where every Data Structure and Algorithm becomes part of an immersive medieval world.

The game should feel mysterious, adventurous, rewarding and nostalgic.

The player should always feel like they are exploring an ancient forgotten kingdom rather than solving coding problems.

# UI/UX Principles

- Never overwhelm the player.
- Maximum 5 primary options on one screen.
- Every button must provide visual feedback.
- Every interaction should have a sound or animation.
- Important objects should naturally attract attention.
- New mechanics are introduced one at a time.
- Hints should guide, not reveal the solution.
- Learning should feel like exploration, not examination.
